# Feria del Estudiante - ASIR

Web estática para promocionar ASIR durante la Feria del Estudiante.

## Archivos

- `index.html`: estructura y contenido.
- `style.css`: diseño responsive.
- `script.js`: funcionamiento del quiz.

## Probar en local

Abre `index.html` directamente en el navegador.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub, por ejemplo `feria-asir`.
2. Sube estos archivos a la raíz del repositorio.
3. En el repositorio abre `Settings` > `Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/(root)`.
6. Guarda los cambios.
7. GitHub mostrará la URL pública cuando el despliegue esté listo.

## Siguiente paso

Cuando tengas la URL pública, genera un código QR con esa dirección y pásaselo al responsable del diseño del stand para incorporarlo a los carteles.
